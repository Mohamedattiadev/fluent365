# Security and privacy reports

Please report security or privacy problems privately using GitHub's **Security → Report a vulnerability** on this repository (private advisory), not a public issue.

Include what you found, how to reproduce it and its impact. Don't include real learner data.

Scope: the Pocket app (`apps/pocket`), the service worker, import handling (PDF/text/backup files) and the deployment workflows. Fluent365 has no server and stores no user data centrally.
