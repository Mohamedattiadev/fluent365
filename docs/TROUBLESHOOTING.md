# Troubleshooting

| Problem | What to do |
|---|---|
| "Content could not be loaded" | Connect to the internet once and reload. After that it works offline. |
| My progress disappeared | Browser data was cleared, or you opened a different address/browser. Restore your last backup: Settings → Backup → Choose backup file. |
| No sound in listening | The app uses your device's voices. Android: Settings → System → Languages → Text-to-speech → install an English voice. Check the volume. |
| Recording doesn't work | Allow microphone access for the site in your browser settings. You can always practise out loud without recording. |
| "Install app" isn't offered | Use Chrome, open the page over https (GitHub Pages does this), wait a few seconds, then try the ⋮ menu again. |
| Fluent365 isn't in the Android share list | Install the app first (share targets only work for installed apps), then reopen the share menu. |
| A PDF import finds nothing | Scanned PDFs (pictures of text) can't be read yet. Copy the text and paste it into the Import Centre. |
| Too many reviews | That's normal after a break. Fluent365 automatically adds fewer new words until reviews are under control. You can also lower "New words per day" in Settings. |
| GitHub Pages deploy fails | Settings → Pages → Source must be *GitHub Actions*; Actions must be enabled for the repository. |
